Last Gnome Standing

A chaotic local multiplayer game where players fight as gnomes to be the last one standing, built from scratch in Unity with custom physics and character mechanics.

My Role Game designer & Unity developer
Tech & tools
Unity C# Game design Character art

Context & problem

The challenge was a game that is fun right away without a tutorial: clear visual feedback, responsive controls and chaotic but fair mechanics that keep everyone engaged from round one.

Target audience

Casual gamers, local multiplayer fans and game jam enthusiasts who like fast competitive games.

Features

Physics-driven knockback, custom animation state machines, arena hazards and a fast respawn loop that keeps rounds short and replayable.

Process

Started with paper prototypes, iterated on how movement feels, and built modular C# scripts for character states and collision detection. Playtested a lot to tune knockback values.

Takeaways

Learned how small changes to friction, speed and hitbox size change how a game feels, and how important playtesting is for good game feel.
