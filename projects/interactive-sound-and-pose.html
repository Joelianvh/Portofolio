Interactive Sound & Pose

A sound installation where visitors' poses and movements trigger and change audio, using computer vision to turn the body into an instrument.

My Role Interaction designer & CV developer
Tech & tools
MediaPipe p5.js Pose detection Web Audio API

Context & problem

Traditional music interfaces require technical knowledge. This project asked what happens if anyone can make music just by moving. The challenge was making pose detection expressive but accessible.

Target audience

Exhibition visitors, children and adults without a musical background, and researchers of embodied interaction.

Features

Real-time 33-point pose tracking, mapping gestures to audio parameters (pitch, volume, effects), a visual feedback overlay and low-latency audio triggering with the Web Audio API.

Process

Used MediaPipe Pose to track keypoints, mapped joint angles and distances to musical parameters, and tuned sensitivity by observing users, to balance precision and playfulness.

Takeaways

Designing the body as an interface requires empathy for how people naturally move. Over-engineering gesture detection makes interactions feel clinical instead of expressive.
