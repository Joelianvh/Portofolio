Ableton Sound Control

A custom physical controller interface that bridges hardware inputs with Ableton Live — enabling expressive, gesture-driven music performance through sensor-mapped MIDI control.

My Role Interaction Designer & Hardware Hacker
Tech & Tools Used
Ableton Live MIDI Arduino Physical Computing
Links & Sources View Build

Context & Problem

Standard MIDI controllers limit expressive performance. The goal was to map non-traditional sensor inputs — pressure, distance, rotation — to Ableton parameters to unlock new performance gestures.

Target Audience

Electronic musicians, live performers, and interaction designers interested in alternative human-computer music interfaces.

Key Features

Real-time MIDI mapping of sensor values, custom parameter scaling, low-latency USB serial communication, and a modular design that allows swapping sensor types between sessions.

Process & Technical Insight

Wired Arduino sensors to read analog inputs, converted readings to MIDI CC values, and routed via USB to Ableton. Iterated on sensitivity curves and deadzone thresholds to eliminate noise and make the controller feel expressive.

Personal Takeaways

Building a custom instrument taught me that interface design is performance design — the physical feel of an input is inseparable from the creative output it enables.

Interactive Sound & Pose

A body-driven sound installation where participant poses and movements trigger and modulate audio — transforming the human body into a live instrument using computer vision.

My Role Interaction Designer & CV Developer
Tech & Tools Used
MediaPipe p5.js Pose Detection Web Audio API
Links & Sources View Demo

Context & Problem

Traditional music interfaces require technical knowledge. This project asked: what if anyone could make music just by moving their body? The challenge was making pose detection expressive yet accessible.

Target Audience

Exhibition visitors, children and adults without musical backgrounds, and creative tech researchers exploring embodied interaction.

Key Features

Real-time 33-point body pose tracking, gesture-to-audio parameter mapping (pitch, volume, effects), visual feedback overlay, and zero-latency audio triggering via the Web Audio API.

Process & Technical Insight

Used MediaPipe Pose to track keypoints, mapped joint angles and distances to musical parameters, and tuned sensitivity thresholds through extensive user observation sessions to find the right balance between precision and playful expressiveness.

Personal Takeaways

Body-as-interface design requires empathy for how people naturally move — over-engineering gesture detection makes interactions feel clinical rather than expressive and joyful.

A fully designed and built escape room experience — combining narrative puzzle design, atmospheric staging, and interactive electronic triggers for an immersive 60-minute adventure.

My Role Escape Room Designer & Interactive Systems Builder
Tech & Tools Used
Arduino Puzzle Design Prop Making Experience Design
Links & Sources View Room Design

Context & Problem

Escape rooms live or die by their puzzle logic and atmosphere. The challenge was designing puzzles that feel satisfying to solve — neither too obvious nor cryptic — while building an environment that immerses players from the moment they enter.

Target Audience

Groups of 2–6 players looking for a challenging and atmospheric puzzle experience, as well as experience design researchers studying spatial narrative.

AKOb Heart Project

A biometric interactive installation that reads participant heartbeats and translates them into real-time visual and audio responses — creating an intimate, data-driven portrait of the body's inner rhythm.

My Role Biometric Interaction Designer & Installation Builder
Tech & Tools Used
Heart Rate Sensor Arduino Processing Biometric Data
Links & Sources View Installation

Context & Problem

Biometric data is usually invisible and clinical. The challenge was making heart rate data felt and seen in a way that is poetic, personal, and immediately understandable — without requiring the participant to read a chart.

Target Audience

Exhibition visitors, healthcare design researchers, and anyone interested in the relationship between body data and emotional expression.

Key Features

Real-time heart rate detection via optical sensor, generative visual output that pulses with BPM, ambient audio that shifts in texture with heart rate variability, and a participant-facing display showing their live heartbeat waveform.

Process & Technical Insight

Calibrated the optical heart rate sensor to minimise motion noise, built a smoothing algorithm to stabilise BPM readings, and mapped values to visual parameters through iterative observation of how participants emotionally responded to different representations of their own heartbeat.

Personal Takeaways

Making the invisible visible — turning something as private as a heartbeat into a shared public experience — showed me how powerful biometric data can be as a medium for human connection and self-reflection.
